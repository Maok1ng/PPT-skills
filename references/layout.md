以下坐标使用 1280 × 720 画布（16:9），保留参考文件尺寸。不要复制网页播放器边框、视频水印或进度条。

字体可用时使用以上字体。缺失时选择相近且含中文的字体，如 Noto Serif CJK SC / 宋体，并重新渲染检查；不要为了模板擅自安装全局字体。字体大小为 Artifact Tool 的像素单位，不能直接当作 PowerPoint 的磅值。

长标题先精炼文字，保留完整主题，避免自动换成“章节编号 + 短词”的页眉。若仍放不下，局部调整到 28–30 px 并检查，不统一缩小全稿。正文不要依赖 `shrinkText` 掩盖溢出。

## 常用版式选择

- 封面：论文短名大字、中文研究主题、作者与出处，保持留白。
- 背景与问题：一张代表性原图，下方 2–3 行写输入、输出和核心困难。
- 方法总览：完整框架图，下方 1–2 行概括表示和优化。
- 公式推导：上、中、下最多 3 组公式，紧邻说明各项含义及假设。
- 模块分析：论文图 + 简短机制解释，可使用左右两栏。
- 实验结果：完整主要表格，下方 1–2 条直接分析，不另做重复数字大字报。
- 总结：贡献与局限两栏，启发可单页并放简短参考文献。

优先借用对应参考页，保留页眉页脚结构。可增删页，但所有页码重新连续编号，底栏短主题与内容同步。页脚左侧写当前论文名，不能遗留 MotionScale。

局部编辑以用户最新文件为准，不因该页未使用上述默认值而顺手重设整稿。避免反复堆叠带背景的大框；优先用对齐、留白、细线或原生表格体现层次。用户要求简化时先调整信息密度和阅读顺序，再调配色。封面和尾页默认白底；仅在用户要求时把尾页改成指定致谢文字，不自动新增一页挤占讲述时长。
